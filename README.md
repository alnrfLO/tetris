# 🧱 Tetris

Remake de **Tetris** en Python avec **Pygame**.

## Fonctionnalités

- Les 7 pièces classiques, avec leur rotation
- Aperçu de la pièce suivante
- Suppression des lignes complètes
- Menu de démarrage et écran de défaite

## Contrôles

| Touche | Action |
|---|---|
| `←` / `→` | Déplacer la pièce |
| `↑` | Faire tourner la pièce |
| `↓` | Accélérer la descente |
| `Espace` | Faire tomber la pièce d'un coup |

## Installation

```bash
pip install pygame
python Tetris.py
```

## Technologies

- Python 3
- Pygame
